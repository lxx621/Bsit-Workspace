## 2. 字体体系

### 2.1 字体家族
```css
font-family: -apple-system, BlinkMacSystemFont, Roboto, Arial, Helvetica, 
  "Segoe UI", "Noto Sans", sans-serif, 
  "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", "Noto Color Emoji";
```

### 2.2 字号规范
| 等级 | 字号 | 用途 |
|------|------|------|
| 超大 | 20px | 页面大标题 |
| 大号 | 18px | 模块标题 |
| 中号 | 16px | 卡片标题、重要文字 |
| 基础 | 14px | 正文、表格、按钮 |
| 小号 | 13px | 辅助文字 |
| 超小 | 12px | 注释、标签 |

### 2.3 字重与行高
- **主字重**: 500 (medium)
- **主行高**: 24px

## 6. 布局系统

### 6.1 整体框架 (混合布局模式 is-mix)
```
┌──────────────────────────────────────────────────────┐
│ 顶部导航栏 (header: 54px高, 白色背景, 底部分割线)        │
│ ┌──────┐ ┌───────────────────────────────────────┐   │
│ │ Logo │ │ 一级菜单(水平) │ 面包屑 │ 工具栏 │ 用户 │   │
│ └──────┘ └───────────────────────────────────────┘   │
├──────────┬───────────────────────────────────────────┤
│ 侧边栏   │ 内容区域                                    │
│ 160px宽  │ ┌─────────────────────────────────────┐   │
│ 白色背景  │ │ Tab标签页栏                            │   │
│          │ ├─────────────────────────────────────┤   │
│ 二级菜单  │ │ 主内容区 (背景色: #f7f7f9)             │   │
│ (垂直)   │ │                                      │   │
│          │ │                                      │   │
│          │ └─────────────────────────────────────┘   │
│          │ ┌─────────────────────────────────────┐   │
│          │ │ 页脚 (官网 | 文档 | 授权 | Copyright)  │   │
│          │ └─────────────────────────────────────┘   │
└──────────┴───────────────────────────────────────────┘
```

### 6.2 顶部导航栏
- **高度**: 54px
- **背景**: 白色 `#ffffff`
- **分割线**: 底部 `show-divider`
- **组成**: Logo区 → 一级菜单(水平menubar) → 面包屑 → 工具栏(语言/通知/用户/主题)
- **Logo**: "Ele Admin Plus" H1标题

### 6.3 侧边栏 (ele-admin-sidebar is-mix)
- **宽度**: 160px
- **背景**: 白色
- **内容**: 当前一级菜单下的二级菜单项
- **菜单项高度**: 56px (一级) / 50px (二级)
- **菜单激活色**: 主色 `#2f54eb`
- **悬浮背景**: `var(--el-color-primary-light-9)`
- **左侧内边距**: 16px

### 6.4 Tab标签页系统
- **位置**: 内容区域顶部
- **功能**: 页面切换、多页签管理
- **交互**: 点击切换、右键菜单(关闭/固定等)

## 7. 核心组件规范

### 7.1 按钮 (Button)
| 属性 | 主按钮 | 默认按钮 |
|------|--------|----------|
| 背景色 | `#2f54eb` | `#ffffff` |
| 文字色 | `#ffffff` | `rgba(0,0,0,.88)` |
| 圆角 | 6px | 6px |
| 字号 | 14px | 14px |
| 高度 | 32px | 32px |
| 内边距 | 8px 12px | 8px 12px |

### 7.2 表格 (Table)
- **表头背景**: `rgb(247, 247, 247)`
- **字号**: 14px
- **行高**: 自适应
- **边框**: 浅灰色分割线
- **功能列**: 序号 / 复选框 / 数据列 / 操作列
- **操作按钮**: 文字链接形式 (修改/删除/更多)

### 7.3 表单 (Form)
- **标签位置**: 右对齐
- **输入框高度**: 32px
- **必填标识**: 红色 `*` 号
- **验证方式**: 失焦/提交时验证

### 7.4 对话框 (Dialog)
- **遮罩**: `rgba(255, 255, 255, 0.4)`
- **圆角**: 6px
- **结构**: 标题栏 → 内容区 → 操作栏(取消/保存)

### 7.5 分页器 (Pagination)
- **组成**: 总条数 → 上一页 → 页码 → 下一页 → 每页条数 → 跳转
- **默认每页**: 20条

### 7.6 搜索栏
- **布局**: 水平行内表单
- **组成**: 筛选字段 → 搜索按钮(主色) → 重置按钮
- **位置**: 表格上方

### 7.7 工具栏
- **位置**: 搜索栏与表格之间
- **组成**: 添加(主色) → 删除(红色) → 导入/导出 → 列设置/刷新/密度
