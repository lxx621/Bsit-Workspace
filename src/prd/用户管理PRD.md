# 用户管理模块 PRD

> 模块路由: `/system/user`  
> 所属: 系统管理  
> 权限操作: 查询用户、添加用户、修改用户、删除用户、用户详情

---

## 1. 功能概述

用户管理模块提供对系统用户的全生命周期管理能力，包括用户的增删改查、状态控制、密码管理、角色分配及机构关联。页面采用左树右表的经典布局，左侧为机构树，右侧为用户列表。

### 2.2 左侧机构树
- **搜索框**: 输入机构名称进行过滤

- **选中效果**: 点击节点筛选右侧表格数据
- **默认状态**: 全部展开

## 4. 逻辑功能设计

### 4.1 页面加载流程
1. 请求机构树数据 → 渲染左侧Tree
2. 请求用户列表(默认第1页，20条/页) → 渲染表格
3. 请求字典数据(性别) → 填充搜索栏下拉

### 4.2 机构树筛选
- 点击树节点 → 携带organizationId重新查询用户列表
- 搜索框输入 → 前端过滤树节点(filterNode)

### 4.3 搜索与重置
- **搜索**: 收集搜索栏表单值 → 重置页码为1 → 请求列表
- **重置**: 清空搜索栏所有字段 → 重置页码为1 → 请求列表

### 4.4 添加用户
1. 点击"添加"按钮 → 打开Dialog弹窗
2. 表单填写 → 前端校验(必填+格式)
3. 点击"保存" → 调用添加API → 成功提示 → 关闭弹窗 → 刷新列表

### 4.5 修改用户
1. 点击"修改" → 回填数据到Dialog表单(密码字段隐藏)
2. 修改后保存 → 调用修改API → 成功提示 → 关闭弹窗 → 刷新列表

### 4.6 删除用户
- **单个删除**: 更多 → 删除用户 → 确认弹窗 → 调用删除API
- **批量删除**: 勾选多条 → 点击"删除"按钮 → 确认弹窗 → 批量删除API

### 4.7 状态切换
- 点击Switch开关 → 二次确认 → 调用状态修改API → 更新行数据

### 4.8 重置密码
- 更多 → 重置密码 → 确认弹窗 → 调用重置密码API → 提示新密码

### 4.9 导入用户
- 点击"导入" → 上传Excel/CSV文件 → 后端解析 → 返回导入结果

### 4.10 分页逻辑
- 支持页码切换、每页条数切换(20/50/100)、跳转指定页
- 切换条件后自动重置到第1页
