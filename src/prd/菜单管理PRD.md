# 菜单管理模块 PRD

> 模块路由: `/system/menu`  
> 所属: 系统管理  
> 权限操作: 查询菜单、添加菜单、修改菜单、删除菜单

---

## 1. 功能概述

菜单管理模块负责系统导航菜单和按钮权限的配置。菜单分为三种类型：目录(一级导航)、菜单(具体页面)、按钮(操作权限)。采用树形表格展示，支持无限层级嵌套，是权限体系的基础配置模块。

### 2.2 搜索栏
| 字段 | 组件 | 说明 |
|------|------|------|
| 菜单名称 | 文本输入 | 模糊搜索 |
| 菜单地址 | 文本输入 | 路由地址搜索 |
| 权限标识 | 文本输入 | 权限编码搜索 |

### 2.3 表格列定义
| 列名 | 字段 | 说明 |
|------|------|------|
| 菜单名称 | title | 带树形展开图标 |
| 路由地址 | path | 页面路由/外链URL |
| 排序 | sortNumber | 数字排序 |
| 可见 | hide | 是/否 |
| 类型 | menuType | 目录/菜单/按钮/外链 |
| 操作 | action | 添加/修改/删除 |

### 2.4 特殊说明
- **树形表格**: 不使用分页，一次性加载全部菜单数据
- **展开/折叠**: 全局控制所有层级的展开/折叠
- **操作列**: 每行均可添加子级、修改、删除

## 3. 数据结构设计

### 3.1 菜单实体 (Menu)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| menuId | Long | 是 | 主键ID |
| parentId | Long | 否 | 上级菜单ID(0为顶级) |
| title | String | 是 | 菜单名称 |
| path | String | 否 | 路由地址 |
| component | String | 否 | 组件路径 |
| menuType | Integer | 是 | 类型(0目录/1菜单/2按钮/3外链) |
| sortNumber | Integer | 是 | 排序号 |
| authority | String | 否 | 权限标识 |
| icon | String | 否 | 菜单图标 |
| hide | Integer | 是 | 是否隐藏(0否/1是) |
| createTime | DateTime | 自动 | 创建时间 |

### 3.2 菜单树层级示例
```
目录(Dashboard)
  └─ 菜单(工作台)
  └─ 菜单(分析页)
目录(系统管理)
  └─ 菜单(用户管理)
      └─ 按钮(查询用户)
      └─ 按钮(添加用户)
      └─ 按钮(修改用户)
      └─ 按钮(删除用户)
      └─ 按钮(用户详情)
```

### 3.3 API接口
| 接口 | 方法 | 路径 |
|------|------|------|
| 查询全部 | GET | /api/system/menu |
| 添加菜单 | POST | /api/system/menu |
| 修改菜单 | PUT | /api/system/menu |
| 删除菜单 | DELETE | /api/system/menu/{id} |

## 4. 逻辑功能设计

### 4.1 添加菜单
- 点击顶部"添加" → 添加顶级菜单(parentId=0)
- 点击行内"添加" → 添加当前菜单的子级(parentId=当前行ID)
- 表单根据类型动态显示字段：
  - **目录**: 名称、路径、图标、排序、可见
  - **菜单**: 名称、路径、组件、图标、排序、可见
  - **按钮**: 名称、权限标识、排序
  - **外链**: 名称、链接地址、排序、可见

### 4.2 删除菜单
- 如果有子级菜单，需要先删除子级或提示"请先删除子菜单"
- 删除后检查关联的角色权限是否受影响

### 4.3 展开/折叠
- "展开全部": 遍历树表格，展开所有行
- "折叠全部": 收起所有树节点至一级

### 4.4 搜索逻辑
- 前端过滤树形数据，匹配的节点及其父节点均展示
