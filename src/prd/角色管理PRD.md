# 角色管理模块 PRD

> 模块路由: `/system/role`  
> 所属: 系统管理  
> 权限操作: 查询角色、添加角色、修改角色、删除角色

---

## 1. 功能概述

角色管理模块负责系统角色的定义与权限分配。角色是RBAC权限模型的核心实体，通过为角色分配菜单权限（包括页面访问权限和按钮操作权限），再将角色关联到用户，实现细粒度的访问控制。

## 3. 数据结构设计

### 3.1 角色实体 (Role)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| roleId | Long | 是 | 主键ID |
| roleName | String | 是 | 角色名称 |
| roleCode | String | 是 | 角色标识，唯一 |
| comments | String | 否 | 备注说明 |
| createTime | DateTime | 自动 | 创建时间 |

### 3.2 角色-菜单关联 (RoleMenu)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键 |
| roleId | Long | 角色ID |
| menuId | Long | 菜单ID |

### 3.3 添加/编辑角色表单
| 字段 | 组件 | 必填 |
|------|------|------|
| 角色名称 | 文本输入 | 是 |
| 角色标识 | 文本输入 | 是 |
| 备注 | 文本域 | 否 |

### 3.4 分配权限弹窗
- **组件**: Dialog + Tree(带复选框)
- **树数据**: 完整菜单权限树（目录→菜单→按钮三级）
- **选中状态**: checked(全选) / mixed(半选) / unchecked(未选)
- **权限树示例**:
  ```
  ☑ Dashboard
    ☑ 工作台
    ☑ 分析页
    ☑ 监控页
  ☐ 系统管理
    ◈ 用户管理 (半选)
      ☑ 查询用户
      ☐ 添加用户
      ☐ 修改用户
      ☐ 删除用户
      ☑ 用户详情
  ```

## 4. 逻辑功能设计

### 4.1 分配权限流程
1. 点击"分配权限" → 请求该角色已分配的菜单ID列表
2. 同时请求完整菜单树 → 合并生成带选中状态的权限树
3. 用户勾选/取消 → 父子级联动(半选机制)
4. 点击"保存" → 收集所有选中的menuId → 调用保存API
5. 成功后关闭弹窗

### 4.2 RBAC权限模型
```
用户(User) ──N:1──> 角色(Role) ──N:N──> 菜单(Menu)
```
- 一个用户关联一个角色
- 一个角色关联多个菜单/按钮权限
- 菜单权限控制页面访问，按钮权限控制功能操作

### 4.3 删除保护
- 删除角色前需检查是否有用户关联该角色
- 如有关联，提示"该角色下存在用户，不允许删除"
