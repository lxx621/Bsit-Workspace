# 机构管理模块 PRD

> 模块路由: `/system/organization`  
> 所属: 系统管理  
> 权限操作: 查询机构、添加机构、修改机构、删除机构

---

## 1. 功能概述

机构管理模块用于维护系统的组织架构信息，支持多级机构的树形管理。机构类型包括公司、部门、小组等，采用树形表格展示层级关系，为用户管理提供机构归属的基础数据。

## 3. 数据结构设计

### 3.1 机构实体 (Organization)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| organizationId | Long | 是 | 主键ID |
| parentId | Long | 否 | 上级机构ID(0为顶级) |
| organizationName | String | 是 | 机构名称(简称) |
| organizationFullName | String | 是 | 机构全称 |
| organizationCode | String | 否 | 机构代码 |
| organizationType | Integer | 是 | 机构类型(字典: 公司/部门/小组) |
| sortNumber | Integer | 是 | 排序号 |
| comments | String | 否 | 备注 |
| createTime | DateTime | 自动 | 创建时间 |

### 3.2 添加/编辑机构表单
| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|
| 上级机构 | 下拉树选择 | 否 | 不选则为顶级 |
| 机构名称 | 文本输入 | 是 | 简称 |
| 机构全称 | 文本输入 | 是 | 完整名称 |
| 机构代码 | 文本输入 | 否 | 编码 |
| 机构类型 | 下拉选择 | 是 | 字典数据 |
| 排序号 | 数字输入 | 是 | 0-99999 |
| 备注 | 文本域 | 否 | 说明信息 |

### 3.3 API接口
| 接口 | 方法 | 路径 |
|------|------|------|
| 查询全部 | GET | /api/system/organization |
| 添加机构 | POST | /api/system/organization |
| 修改机构 | PUT | /api/system/organization |
| 删除机构 | DELETE | /api/system/organization/{id} |

## 4. 逻辑功能设计

### 4.1 树形层级管理
- 公司(顶级) → 部门 → 小组，支持更深层级
- 添加子机构时自动设置parentId
- 排序号决定同级的显示顺序

### 4.2 删除保护
- 有子机构时不允许删除，需先删除子机构
- 有关联用户时不允许删除，需先转移用户

### 4.3 与用户管理的关联
- 用户管理左侧树数据来源于机构管理
- 机构变更时需同步更新用户关联
