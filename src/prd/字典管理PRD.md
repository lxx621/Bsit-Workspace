# 字典管理模块 PRD

> 模块路由: `/system/dictionary`  
> 所属: 系统管理  
> 权限操作: 查询字典、添加字典、修改字典、删除字典

---

## 1. 功能概述

字典管理模块用于维护系统中的枚举值/选项数据。采用左侧字典列表+右侧字典数据的主从布局，实现字典分类与字典项的统一管理。字典数据广泛应用于下拉选择、状态显示等场景。

---

│           │ ┌─────────────────────────────────────┐ │

### 2.2 左侧字典列表
- **搜索框**: 输入字典名称过滤
- **操作按钮**: 添加/修改/删除 字典分类
- **字典项**: 以Tree形式展示，格式"名称 (编码)"
- **选中效果**: 点击加载右侧对应字典数据

### 2.3 右侧字典数据表格
| 列名 | 字段 | 说明 |
|------|------|------|
| 复选框 | selection | 多选 |
| 字典数据名 | dictDataName | 显示文本 |
| 字典数据值 | dictDataCode | 存储值 |
| 排序号 | sortNumber | 排序 |
| 创建时间 | createTime | 日期时间 |
| 操作 | action | 修改/删除 |

## 3. 数据结构设计

### 3.1 字典实体 (Dictionary)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| dictId | Long | 是 | 主键ID |
| dictName | String | 是 | 字典名称 |
| dictCode | String | 是 | 字典编码，唯一 |
| comments | String | 否 | 备注 |
| createTime | DateTime | 自动 | 创建时间 |

### 3.2 字典数据实体 (DictionaryData)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| dictDataId | Long | 是 | 主键ID |
| dictId | Long | 是 | 所属字典ID |
| dictDataName | String | 是 | 数据名称(显示文本) |
| dictDataCode | String | 是 | 数据值(存储值) |
| sortNumber | Integer | 是 | 排序号 |
| comments | String | 否 | 备注 |
| createTime | DateTime | 自动 | 创建时间 |

### 3.3 现有字典分类
| 字典名称 | 字典编码 | 字典项 |
|----------|----------|--------|
| 用户性别 | sex | 男(1), 女(2) |
| 机构类型 | organization_type | 公司, 部门, 小组 |
| 状态 | status | 正常, 冻结 |

| 删除字典 | DELETE | /api/system/dictionary/{id} |
| 分页查询字典数据 | GET | /api/system/dictionary-data/page |

## 4. 逻辑功能设计

### 4.1 字典使用方式
- 其他模块通过字典编码(dictCode)获取字典数据列表
- 表单下拉框通过dictCode加载选项
- 表格通过dictDataCode映射显示dictDataName

### 4.2 左右联动
- 选中左侧字典 → 携带dictId查询右侧字典数据
- 左侧搜索 → 前端过滤字典列表
- 添加字典数据时自动关联当前选中的字典

### 4.3 缓存策略
- 字典数据应在前端缓存，减少重复请求
- 字典变更后需刷新缓存
