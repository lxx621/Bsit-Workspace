# 文件管理模块 PRD

> 模块路由: `/system/file`  
> 所属: 系统管理  
> 权限操作: 上传文件、删除文件、查看记录

---

## 1. 功能概述

文件管理模块提供系统级的文件上传、存储、下载和管理功能。支持多种文件类型（图片、文档、JSON等），提供文件列表浏览、搜索筛选、下载和删除操作。文件采用日期目录+UUID重命名的存储策略。

### 2.2 搜索栏
| 字段 | 组件 | 说明 |
|------|------|------|
| 文件名称 | 文本输入 | 原始文件名模糊搜索 |
| 文件路径 | 文本输入 | 存储路径搜索 |
| 上传人 | 文本输入 | 上传者名称搜索 |

### 2.3 表格列定义
| 列名 | 字段 | 说明 |
|------|------|------|
| 复选框 | selection | 多选 |
| 序号 | index | 自动编号 |
| 文件名称 | fileName | 原始文件名 |
| 文件路径 | filePath | 可点击链接，跳转预览 |
| 文件大小 | fileSize | 格式化显示(KB/MB) |
| 上传人 | createUsername | 上传者名称 |
| 上传时间 | createTime | 日期时间 |
| 操作 | action | 下载(链接)/删除 |

### 2.4 操作说明
- **上传**: 按钮触发文件选择，支持多文件
- **下载**: 链接形式，直接触发浏览器下载
- **删除**: 文字按钮，确认后删除文件记录及物理文件
- **文件路径**: 可点击链接，打开新窗口预览

## 3. 数据结构设计

### 3.1 文件实体 (FileRecord)
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| fileId | Long | 是 | 主键ID |
| fileName | String | 是 | 原始文件名 |
| filePath | String | 是 | 存储路径(日期/UUID.ext) |
| fileSize | Long | 是 | 文件大小(字节) |
| contentType | String | 否 | MIME类型 |
| createUserId | Long | 是 | 上传人ID |
| createUsername | String | 是 | 上传人名称 |
| createTime | DateTime | 自动 | 上传时间 |

### 3.2 文件存储策略
- **目录规则**: `yyyyMMdd/UUID.原始扩展名`
- **示例**: `20220722/b7bac0f9abdb4b0f94b911940a77ad3b.jpg`
- **基础URL**: `http://域名/api/file/`
- **下载URL**: `http://域名/api/file/download/路径`

### 3.3 API接口
| 接口 | 方法 | 路径 |
|------|------|------|
| 分页查询 | GET | /api/file/page |
| 上传文件 | POST | /api/file/upload |
| 删除文件 | DELETE | /api/file/{id} |
| 下载文件 | GET | /api/file/download/{path} |
| 预览文件 | GET | /api/file/{path} |

## 4. 逻辑功能设计

### 4.1 文件上传流程
1. 点击"上传"按钮 → 触发文件选择器(可多选)
2. 选择文件 → FormData封装 → POST上传
3. 后端：生成UUID文件名 → 按日期创建目录 → 保存文件 → 写入数据库
4. 上传成功 → 刷新列表

### 4.2 文件下载
- 点击"下载"链接 → 浏览器直接下载
- 使用`Content-Disposition: attachment`强制下载

### 4.3 文件预览
- 点击"文件路径"链接 → 新窗口打开文件URL
- 图片类型浏览器直接预览
- 其他类型由浏览器决定处理方式

### 4.4 批量操作
- 勾选多条记录 → 点击"删除"按钮 → 确认弹窗 → 批量删除

### 4.5 文件大小格式化
- < 1KB: 显示字节数
- < 1MB: 显示KB(保留2位小数)
- >= 1MB: 显示MB(保留2位小数)
