# 登录日志模块 PRD

> 模块路由: `/system/login-record`  
> 所属: 系统管理  
> 权限操作: 查看(只读)

---

## 1. 功能概述

登录日志模块记录并展示所有用户的登录行为。自动采集登录账号、IP地址、设备信息、浏览器类型及登录结果等关键信息。仅提供查询和导出功能，数据由系统自动写入，不支持手动修改或删除。

## 3. 数据结构设计

### 3.1 登录日志实体 (LoginRecord)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键ID |
| username | String | 登录账号 |
| nickname | String | 用户名 |
| ip | String | 客户端IP |
| device | String | 设备型号/操作系统版本 |
| os | String | 操作系统类型 |
| browser | String | 浏览器类型 |
| loginType | Integer | 操作类型(0成功/1失败) |
| comments | String | 备注(失败原因) |
| createTime | DateTime | 登录时间 |

### 3.2 API接口
| 接口 | 方法 | 路径 |
|------|------|------|
| 分页查询 | GET | /api/system/login-record/page |
| 导出Excel | GET | /api/system/login-record/export |

## 4. 逻辑功能设计

### 4.1 数据采集(后端自动)
- 登录接口成功/失败时自动写入日志
- 通过HTTP请求头解析：User-Agent → 设备/OS/浏览器
- 通过请求IP解析客户端地址

### 4.2 搜索逻辑
- 日期范围查询：createTime BETWEEN startDate AND endDate
- 文本字段支持模糊匹配(LIKE)

### 4.3 导出功能
- 导出当前筛选条件下的全部数据(非仅当前页)
- 格式: Excel(.xlsx)
- 列与表格列一致

### 4.4 分页策略
- 默认按登录时间倒序排列(最新在前)
- 默认每页20条，支持切换
- 数据量可能很大(示例1215条)，需后端分页
