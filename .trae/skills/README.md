## 一、技能管理与扩展

| 技能名称 | 详细描述 |
|---------|---------|
| **find-skills** | 技能发现技能，帮助用户从开放代理技能生态系统中发现和安装技能。当用户询问"如何做X"、"找到X的技能"、"是否有技能可以..."时使用。 |
| **skill-creator** | 技能创建指南，用于创建扩展代理的专业知识、工作流或工具集成的技能。提供技能结构建议和作者检查清单，确保技能可移植、可重建、自构建和凭证安全。 |
| **using-superpowers** | 技能使用指南，在任何对话开始时使用。确立如何查找和使用技能，要求在任何响应（包括澄清问题）之前调用技能工具。强调即使有1%的可能性技能适用，也必须调用。 |
| **mcp-builder** | MCP服务器开发指南，创建使LLM能够通过精心设计的工具与外部服务交互的MCP（模型上下文协议）服务器。支持TypeScript（推荐）和Python，涵盖研究规划、实现、测试、部署全流程。 |

## 二、文档处理与格式转换

| 技能名称 | 详细描述 |
|---------|---------|
| **baoyu-format-markdown** | Markdown格式化工具，将纯文本或Markdown文件转换为结构良好的格式化文档，支持前置元数据、标题、摘要、加粗、列表和代码块。输出格式化后的Markdown文件。 |
| **baoyu-markdown-to-html** | Markdown转HTML转换器，支持微信兼容主题、代码高亮、数学公式、PlantUML、脚注、警告框和信息图。提供default、grace、simple三种主题样式。 |
| **baoyu-url-to-markdown** | URL转Markdown工具，使用Chrome CDP获取网页内容并转换为干净的Markdown格式。支持自动捕获和等待用户信号两种模式，可处理需要登录的页面。 |
| **docx** | Microsoft Word文档处理技能，支持读取、创建和修改.docx文件，可将Markdown转换为格式化的Word文档，支持模板样式生成。 |
| **pptx** | PowerPoint演示文稿处理技能，支持读取、创建和编辑.pptx文件，提供丰富的设计调色板和布局建议，避免创建单调的幻灯片。 |
| **pdf** | PDF处理技能，支持读取、提取文本/表格、合并、拆分、旋转页面、添加水印、创建新PDF、填写表单、加密/解密、提取图片和OCR识别。 |

## 三、视觉设计与创意生成

| 技能名称 | 详细描述 |
|---------|---------|
| **algorithmic-art** | 算法艺术创作技能，使用p5.js创建生成式艺术，支持种子随机性和交互式参数探索。创建原创算法艺术而非复制现有艺术家作品，输出哲学文档(.md)、交互查看器(.html)和生成算法(.js)。 |
| **baoyu-infographic** | 信息图生成器，支持20种布局类型和17种视觉风格。分析内容并推荐最佳布局×风格组合，生成出版级信息图。适用于创建"信息图"、"可视化摘要"等场景。 |
| **baoyu-comic** | 知识漫画创作技能，支持多种艺术风格（清线、日漫、写实、水墨、粉笔）和基调（中性、温馨、戏剧、浪漫等）。创建原创教育漫画，支持分镜布局和连续图像生成。 |
| **baoyu-cover-image** | 文章封面图生成器，支持5个维度（类型、调色板、渲染风格、文字、情绪）定制，包含9种调色板和6种渲染风格。支持电影级(2.35:1)、宽屏(16:9)和方形(1:1)比例。 |
| **canvas-design** | 视觉艺术设计技能，创建美观的.png和.pdf视觉作品。先生成设计哲学(.md)，再通过画布表达视觉理念。强调视觉表达、空间沟通和艺术诠释，文字仅作为视觉点缀。 |

## 五、内容创作与营销策略

| 技能名称 | 详细描述 |
|---------|---------|
| **copywriting** | 营销文案写作技能，为首页、落地页、定价页、功能页、关于页等撰写营销文案。遵循清晰胜于巧妙、利益胜于功能、具体胜于模糊等原则。 |
| **copy-editing** | 文案编辑技能，通过七次扫视框架系统改进现有营销文案：清晰度、语调、价值主张、简洁性、说服力、可信度和行动号召。每次扫视专注一个维度。 |
| **content-strategy** | 内容策略规划技能，帮助规划驱动流量、建立权威和产生线索的内容。区分可搜索内容（捕获现有需求）和可分享内容（创造需求），支持用例内容、枢纽辐射、模板库等内容类型。 |
| **social-content** | 社交媒体内容创作技能，支持LinkedIn、Twitter/X、Instagram、TikTok、Facebook等平台。提供平台策略指南、内容创作、内容复用和排程优化。 |
| **marketing-ideas** | SaaS营销创意库，包含140个经过验证的营销方法，按类别组织：内容与SEO、竞争对手与比较、免费工具与工程、增长黑客、付费广告、合作伙伴、社区建设等。 |
| **pricing-strategy** | 定价策略技能，帮助设计捕获价值、驱动增长并与客户支付意愿一致的定价。涵盖打包策略、定价指标、价格点、Van Westendorp价格敏感度测量等研究方法。 |

## 六、开发工作流与项目管理

| 技能名称 | 详细描述 |
|---------|---------|
| **brainstorming** | 创意头脑风暴技能，在实现任何功能之前必须使用。通过自然协作对话将想法转化为完整的设计和规范，包括探索项目背景、提问澄清、提出方案、呈现设计、编写设计文档。 |
| **writing-plans** | 编写实施计划技能，在接触代码之前使用。编写详细的实施计划，假设工程师对代码库零上下文。记录每个任务需要触摸的文件、代码、测试和验证方法。 |
| **executing-plans** | 执行计划技能，在单独会话中执行书面实施计划。批量执行任务，在批次之间报告审查，遵循加载计划、执行批次、报告、继续的流程。 |
| **subagent-driven-development** | 子代理驱动开发技能，在当前会话中执行具有独立任务的实施计划。每个任务派遣新的子代理，执行后进行两阶段审查（规范合规性审查和代码质量审查）。 |
| **planning-with-files** | 文件规划工作流技能，使用Manus风格的持久Markdown文件进行规划、进度跟踪和知识存储。创建task_plan.md、notes.md和交付文件的三文件模式。 |
| **systematic-debugging** | 系统化调试技能，四阶段根本原因分析流程：重现（必须能复现）、隔离（消除变量）、诊断（找到根本原因）、修复（实施并验证）。强调科学消除过程而非猜测。 |

## 七、代码审查与质量保证

| 技能名称 | 详细描述 |
|---------|---------|
| **code-reviewer** | 代码审查技能，识别安全漏洞、性能问题和代码质量问题。按优先级顺序审查：安全→性能→正确性→可维护性。包含SQL注入防护、XSS防护、N+1查询、错误处理、命名规范等规则。 |
| **frontend-code-review** | 前端代码审查技能，专门审查.tsx、.ts、.js文件。支持待更改审查和目标文件审查两种模式，按紧急程度和类别（代码质量、性能、业务逻辑）组织发现。 |
| **webapp-testing** | Web应用测试技能，使用Playwright与本地Web应用交互和测试。支持验证前端功能、调试UI行为、捕获浏览器截图和查看浏览器日志。提供服务器生命周期管理脚本。 |
| **fix** | 代码修复技能，修复lint错误和格式问题。运行prettier格式化，运行linc检查剩余lint问题，报告需要手动修复的问题。 |

## 八、全栈开发与文档协作

| 技能名称 | 详细描述 |
|---------|---------|
| **fullstack-developer** | 全栈Web开发技能，专精现代JavaScript/TypeScript技术栈：React、Next.js、Node.js、Express、PostgreSQL、MongoDB、Prisma等。支持构建完整Web应用、开发API、创建前端、设置数据库、实现认证、部署和扩展。 |
