## 订单新增 - 完整请求流程

### 流程步骤

```
1. HTTP 请求 → OrderController
   ↓
2. FluentValidation 验证 → OrderCreateDtoValidator
   ↓
3. Controller → OrderService.CreateOrderAsync
   ↓
4. OrderService → Order.Create (领域工厂方法)
   ↓
5. OrderService → OrderRepository.AddAsync
   ↓
6. OrderService → UnitOfWork.CollectEvents (收集领域事件)
   ↓
7. OrderService → UnitOfWork.CommitAsync (提交事务 + 发布事件)
   ↓
8. AutoMapper 映射 → OrderDetailDto
   ↓
9. 返回统一响应 → ApiResult
```

### 详细说明

**步骤 1：接收请求**
- 客户端发送 `POST /api/order` 请求
- 请求体为 JSON 格式的 `OrderCreateDto`
- `AuditLogMiddleware` 记录请求信息

**步骤 2：参数验证**
- `FluentValidation` 自动验证 `OrderCreateDto`
- 验证规则：客户ID非空、订单项非空、地址格式正确等
- 验证失败抛出 `ValidationException`，由 `ExceptionMiddleware` 统一处理

**步骤 3：调用服务**
- `OrderController` 注入 `IOrderService`
- 调用 `CreateOrderAsync(OrderCreateDto dto)` 方法

**步骤 4：创建领域对象**
- `OrderService` 调用 `Order.Create()` 工厂方法
- 创建 `Order` 聚合根，包含 `OrderItem` 实体
- 工厂方法内部触发 `AddDomainEvent(new OrderCreatedEvent(...))`

**步骤 5：保存数据**
- `OrderService` 调用 `_orderRepository.AddAsync(order)`
- `OrderRepository` 使用 SqlSugar 执行 INSERT 操作
- `SqlSugarSetup` 的 `Aop.DataExecuting` 自动赋值 `CreatedAt`、`CreatedBy`

**步骤 6：收集事件**
- `OrderService` 调用 `_unitOfWork.CollectEvents(order)`
- 将聚合根上的领域事件收集到待发布列表

**步骤 7：提交事务**
- `OrderService` 调用 `_unitOfWork.CommitAsync()`
- SqlSugar 提交数据库事务
- 事务成功后，MediatR 逐个发布领域事件
- `OrderCreatedEventHandler` 接收事件并处理（如发送通知、更新库存等）

**步骤 8：对象映射**
- `OrderService` 使用 `_mapper.Map<OrderDetailDto>(order)`
- AutoMapper 根据 `OrderMappingProfile` 配置进行映射
- 忽略 `DomainEvents`、`RowVersion` 等不应返回的字段

**步骤 9：返回响应**
- Service 返回 `ApiResult.Ok(data)`
- `ExceptionMiddleware` 包装为统一 JSON 格式
- `AuditLogMiddleware` 记录响应信息

### 1. Domain 层

**Order.cs（聚合根）**
```csharp
// Domain/Entities/Order/Order.cs
namespace Bsit.SupplyChain.Domain.Entities.Order;

using SqlSugar;
using Bsit.SupplyChain.Domain.Events;
using Bsit.SupplyChain.Domain.Entities.Order.ValueObjects;

/// <summary>
/// 订单聚合根
/// </summary>
[SugarTable("Orders")]
public class Order : BaseEntity
{
    [SugarColumn(IsPrimaryKey = true)]
    public Guid Id { get; private set; }
    
    public string CustomerId { get; private set; }
    public Address ShippingAddress { get; private set; }
    public OrderStatus Status { get; private set; }
    public Money Total { get; private set; }
    
    /// <summary>订单项集合</summary>
    public List<OrderItem> Items { get; private set; } = new();

    private Order() { } // ORM 所需

    /// <summary>
    /// 工厂方法：创建订单
    /// </summary>
    public static Order Create(string customerId, Address address, List<OrderItem> items)
    {
        var order = new Order
        {
            Id = Guid.NewGuid(),
            CustomerId = customerId,
            ShippingAddress = address,
            Status = OrderStatus.Created,
            Items = items,
            Total = CalculateTotal(items)
        };
        
        // 添加领域事件
        order.AddDomainEvent(new OrderCreatedEvent(order.Id, customerId, order.Total.Amount, DateTime.UtcNow));
        return order;
    }

    private static Money CalculateTotal(List<OrderItem> items)
    {
        var total = items.Sum(i => i.UnitPrice.Amount * i.Quantity);
        return new Money(total, items.FirstOrDefault()?.UnitPrice.Currency ?? "CNY");
    }
}
```

// Application/Validators/Order/OrderCreateDtoValidator.cs
namespace Bsit.SupplyChain.Application.Validators.Order;

using FluentValidation;
using Bsit.SupplyChain.Application.Dtos.Order;

/// <summary>
/// 订单创建请求验证器
/// </summary>
public class OrderCreateDtoValidator : AbstractValidator<OrderCreateDto>
{
    public OrderCreateDtoValidator()
    {
        RuleFor(x => x.CustomerId)
            .NotEmpty().WithMessage("客户ID不能为空");

        RuleFor(x => x.ShippingAddress)
            .NotNull().WithMessage("收货地址不能为空")
            .SetValidator(new AddressDtoValidator());

        RuleFor(x => x.Items)
            .NotEmpty().WithMessage("订单项不能为空")
            .Must(items => items.Count > 0).WithMessage("至少包含一个订单项");
    }
}

public class AddressDtoValidator : AbstractValidator<AddressDto>
{
    public AddressDtoValidator()
    {
        RuleFor(x => x.Province).NotEmpty().WithMessage("省份不能为空");
        RuleFor(x => x.City).NotEmpty().WithMessage("城市不能为空");
        RuleFor(x => x.Detail).NotEmpty().WithMessage("详细地址不能为空");
    }
}

**OrderService.cs（服务实现）**
```csharp
// Application/Services/OrderService.cs
namespace Bsit.SupplyChain.Application.Services;

using Bsit.SupplyChain.Application.Interfaces;
using Bsit.SupplyChain.Application.Dtos.Order;
using Bsit.SupplyChain.Domain.Interfaces;
using Bsit.SupplyChain.Domain.Entities.Order;
using Bsit.SupplyChain.Domain.Entities.Order.ValueObjects;
using AutoMapper;
using MediatR;

/// <summary>
/// 订单服务实现
/// </summary>
public class OrderService : IOrderService
{
    private readonly IOrderRepository _orderRepository;
    private readonly IUnitOfWork _unitOfWork;
    private readonly IMapper _mapper;
    private readonly ICurrentUser _currentUser;

    public OrderService(
        IOrderRepository orderRepository,
        IUnitOfWork unitOfWork,
        IMapper mapper,
        ICurrentUser currentUser)
    {
        _orderRepository = orderRepository;
        _unitOfWork = unitOfWork;
        _mapper = mapper;
        _currentUser = currentUser;
    }

    public async Task<<ApiResult<OrderDetailDto>> CreateOrderAsync(OrderCreateDto dto)
    {
        // 开启事务
        _unitOfWork.BeginTran();
        try
        {
            // DTO 转 领域对象
            var address = new Address(dto.ShippingAddress.Province, dto.ShippingAddress.City, dto.ShippingAddress.Detail);
            var items = dto.Items.Select(i => new OrderItem(
                Guid.NewGuid(),
                i.ProductId,
                i.ProductName,
                i.Quantity,
                new Money(i.UnitPrice, "CNY")
            )).ToList();

            // 创建聚合根（工厂方法）
            var order = Order.Create(dto.CustomerId, address, items);

            // 设置审计字段
            order.CreatedBy = _currentUser.UserId;

            // 保存到数据库
            await _orderRepository.AddAsync(order);

            // 收集领域事件
            _unitOfWork.CollectEvents(order);

            // 提交事务 + 发布事件
            await _unitOfWork.CommitAsync();

            // 映射返回 DTO
            return ApiResult.Ok(_mapper.Map<OrderDetailDto>(order));
        }
        catch
        {
            _unitOfWork.Rollback();
            throw;
        }
    }
}
```

namespace Bsit.SupplyChain.Infrastructure.Repositories;

using SqlSugar;

## 总结

**需要创建的文件**：共 12 个文件，分布在 4 个层级
- Domain 层：4 个文件（聚合根、实体、事件、仓储接口）
- Application 层：6 个文件（DTO、验证器、服务接口、服务实现、映射配置、事件处理）
- Infrastructure 层：1 个文件（仓储实现）
- Api 层：1 个文件（控制器）

**请求流程**：HTTP 请求 → 验证 → Service → Domain 创建 → Repository 保存 → UnitOfWork 提交 → 事件发布 → 返回响应

**核心原则**：
- 领域逻辑集中在 Domain 层（工厂方法、领域事件）
- 验证通过 FluentValidation 统一管理
- 事务由 UnitOfWork 协调
- 对象映射通过 AutoMapper 隔离层间数据
- 遵循依赖倒置原则，上层依赖下层接口
